# alu-scripting

Ruby scripts for the regular expressions project.

## Directory: regular_expressions

| File | Description |
|------|-------------|
| 0-simply_match_school.rb | Matches "School" |
| 1-repetition_token_0.rb | Repetition token #0 |
| 2-repetition_token_1.rb | Repetition token #1 |
| 3-repetition_token_2.rb | Repetition token #2 |
| 4-repetition_token_3.rb | Repetition token #3 |
| 5-beginning_and_end.rb | Starts with h, ends with n, one character between |
| 6-phone_number.rb | Matches a 10 digit phone number |
| 7-OMG_WHY_ARE_YOU_SHOUTING.rb | Matches only capital letters |
| 8-textme.rb | Outputs sender, receiver, flags from a TextMe log line |
| 9-passed_linkedin_regex_challenge.jpg | Completed LinkedIn regex puzzle |

## Usage

    cd regular_expressions
    ./0-simply_match_school.rb "Best School"
